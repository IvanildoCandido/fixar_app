# Índice de gates

Use [GATES.md](GATES.md) como checklist mínimo. Aplique também:

- **Segurança:** ameaça, dados, controle, teste negativo e risco residual definidos.
- **Performance:** cenário, métrica e comparação antes/depois reproduzíveis.
- **Revisão:** achados citados, severidade coerente e decisão explícita.
- **Deploy:** versão, artefato, configuração, observabilidade, rollback e autorização confirmados.

Itens não aplicáveis devem receber justificativa curta; não marque itens por inferência.
